# Kandidat Logo — Aksara Nusantara

Empat arah desain baru yang lebih representatif terhadap kata dasar
**"Aksara Nusantara"** (melampaui Bali saja). Palet mengikuti brand existing:

- Saffron `#FF6B35`
- Deep Brown `#2C1810`
- Cream `#FFF8E7`

> File `overview.html` adalah lembar perbandingan mandiri (gambar tertanam)
> agar keempat kandidat bisa dilihat berdampingan di satu halaman.

## Catatan

- Kandidat di atas adalah **konsep raster** (hasil AI). Bila salah satu dipilih,
  disarankan dibuat ulang sebagai **SVG vektor** agar tajam di semua ukuran
  (favicon 16px hingga poster).
- Usulan lanjutan: logo horizontal = `[ikon] AKSARA` dengan subtitle
  "Aksara Nusantara"; logo stacked = ikon di atas wordmark.
